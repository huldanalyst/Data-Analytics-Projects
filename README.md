## Microsot Excel and MySQL 

#### Overview
This project demonstrates the use of Microsoft Excel and MySQL for analyzing and visualizing data. It includes SQL queries for data extraction and transformation, and an Excel dashboard for interactive reporting.

#### Tools Used
- **Microsoft Excel** – PivotTables, Power Pivot and dashboard creation
- **MySQL** – Querying and managing structured data

#### Methodology
-Data Collation and importation into MySQL database
- Connect and extract data from a MySQL database
- Perform data cleaning and preparation
- Analyze data using SQL queries
- Visualize insights through an interactive Excel dashboard
